# mem-flash-cards

Личное приложение для заучивания слов с флеш-карточками и интервальными повторениями.
Чистый HTML/CSS/JS, без фреймворков и сборки. Учебный проект: этап 1 из плана
«чистый JS → PWA → Vite + TypeScript → React».

## Возможности

- Добавление слов с переводом и примером
- Повторение карточек: перевернуть и оценить («Не помню», «Трудно», «Хорошо», «Легко»)
- Интервальные повторения (упрощённый SM-2): чем лучше помните слово, тем реже оно показывается
- Список слов с поиском и удалением
- Экспорт и импорт всех карточек в JSON (бэкап и перенос между устройствами)
- Светлая и тёмная тема (следует настройкам системы)
- Адаптивная вёрстка под iPhone

## Запуск

Сборка не нужна. Откройте `index.html` в браузере (Chrome или Edge).

Для проверки на телефоне выложите проект на GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root) и откройте ссылку в Safari.

## Модель данных

Карточки лежат в `localStorage` под ключом `mfc.cards` как массив объектов:

| Поле                       | Назначение                                                        |
| -------------------------- | ----------------------------------------------------------------- |
| `id`                       | UUID, чтобы устройства не конфликтовали при будущей синхронизации |
| `front`, `back`, `example` | слово, перевод, пример                                            |
| `createdAt`, `updatedAt`   | время создания и последнего изменения (мс)                        |
| `deleted`                  | мягкое удаление: запись остаётся, но скрыта                       |
| `due`                      | когда показать карточку в следующий раз                           |
| `interval`, `ease`, `reps` | состояние алгоритма повторений                                    |

При импорте записи сливаются по `id`, побеждает запись с более поздним `updatedAt`.

## Важно про данные

Данные хранятся только в браузере конкретного устройства. Если очистить данные сайта,
они пропадут. Делайте экспорт в JSON время от времени.
